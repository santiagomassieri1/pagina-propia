Proyectos

Tres scripts propios en Python, escritos para responder preguntas concretas sobre finanzas, inversiones y mi propio proceso de estudio. El código de la izquierda es exactamente el que se ejecuta en la terminal de la derecha: corre en el navegador, sin instalar nada.

  1. 01

    Calculadora de interés compuesto

    Python · Script de consola

    Simula el crecimiento de una inversión a partir del capital inicial, el aporte mensual y el horizonte en años, y compara cinco escenarios de rendimiento anual, del 8% al 17%. El objetivo fue dimensionar cuánto pesa el aporte constante frente a la tasa en el resultado a largo plazo.

  2. 02

    Evaluador de CEDEARs

    Python · Script de consola

    Analiza el rendimiento de una cartera de CEDEARs y calcula la ganancia en pesos y en dólares, ajustando por el dólar CCL del momento de compra contra el actual. Según el resultado, sugiere mantener, vender o esperar. Surgió de aplicar Python a una cartera que ya venía siguiendo de cerca: la mía.

  3. 03

    Evaluador de preguntas

    Python · Script de consola

    Genera un autotest de conceptos de programación —funciones, loops, print— a partir de un diccionario de términos y definiciones, con corrección manual de cada respuesta. Lo uso para repasar contenidos mientras avanzo con Python por mi cuenta.
